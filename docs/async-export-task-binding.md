# 网页后台异步导出任务绑定

适用于点击导出后，后台创建任务、任务中心生成文件，再由 RPA 下载的流程。

## 绑定本轮导出任务

同一时间窗口可能已有历史导出任务，应定位到**本轮触发的任务**再下载：

1. 触发导出前，记录当前导出任务集合、任务数量或其它可稳定比较的现场信息。
2. 记录本轮触发时间，再执行导出动作。
3. 优先使用任务 ID、精确创建时间、唯一任务名等稳定标识定位本轮任务。
4. 页面没有唯一标识时，使用“触发前快照 + 触发时间 + 新增记录”联合判断。
5. 等待本轮任务进入可下载状态后，再点击该任务的下载按钮。
6. 下载完成后校验本地文件属于本轮任务；本地文件创建时间仅作辅助证据。

无法可靠区分本轮任务与历史任务时，停止该数据源并保留旧数据。

## 多地区、多任务分类

后台可能按地区 / 店铺隔离导出任务，并通过任务中心的页签展示商品、库存等任务。使用**地区 / 店铺 + 任务分类 + 本轮新任务**定位：

1. 切换地区前打开地区选择器；选择后等待页面地区、实际 URL / 店铺标识和业务页面完成切换。
2. 进入任务中心后，切换到当前导出所属的任务分类。
3. **每个地区分别**建立导出前任务快照和触发时间，定位新增任务并下载。
4. 不同地区导出同名文件时，分别保存并标记地区，确认文件身份和布局后再拼接。
5. 同一业务结果依赖多个地区文件时，全部必需文件成功且结构一致后再更新结果；失败只阻塞相关业务，不影响其它无依赖任务。

压缩包解压与多文件目标识别参阅 [xzip.md](../xbot-api-docs/docs/xzip.md)；网页下载和等待 API 参阅 [browser.md](../xbot-api-docs/docs/browser.md)。
