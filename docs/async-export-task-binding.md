# 网页后台异步导出任务绑定

适用于点击导出后，后台创建任务、任务中心生成文件，再由 RPA 下载的流程。

## 绑定本轮导出任务

同一时间窗口可能已有历史导出任务，应定位到**本轮触发的任务**再下载：

1. 记录本轮触发时间，执行导出动作。
2. 优先按任务 ID、唯一任务名等稳定标识定位；如无任务 ID，可使用本轮提交时间、文件名和任务分类筛出候选。
3. **候选必须唯一**，才能等待它变为可下载状态并点击对应下载；多条同时匹配或无法区分历史任务时直接报错，不选第一条。
4. 只有上述标识无法可靠绑定本轮任务、且平台提供稳定的任务列表时，才按需要增加“触发前快照 + 触发后新增记录”比对；**不默认预读一次历史任务**。
5. 下载后验证路径、文件存在性和业务结构；本地文件创建时间只是辅助证据。

无法可靠区分本轮任务与历史任务时，停止该数据源并保留旧数据。

## 多地区、多任务分类

后台可能按地区 / 店铺隔离导出任务，并通过任务中心的页签展示商品、库存等任务。使用**地区 / 店铺 + 任务分类 + 本轮新任务**定位：

1. 切换地区前打开地区选择器；选择后等待页面地区、实际 URL / 店铺标识和业务页面完成切换。
2. 进入任务中心后，切换到当前导出所属的任务分类。
3. **每个地区分别**记录导出提交时间和目标文件特征，定位唯一任务并下载；必要时才增加导出前快照。
4. 不同地区导出同名文件时，分别保存并标记地区，确认文件身份和布局后再拼接。
5. 同一业务结果依赖多个地区文件时，全部必需文件成功且结构一致后再更新结果；失败只阻塞相关业务，不影响其它无依赖任务。

压缩包解压与多文件目标识别参阅 [xzip.md](../xbot-api-docs/docs/xzip.md)；网页下载和等待 API 参阅 [browser.md](../xbot-api-docs/docs/browser.md)。

## 动态任务表：避免过期网页元素

React / SPA 后台任务中心可能在数据刷新时替换整行 DOM。实测 Shopee 中，保存 `row` 或 `td` 的影刀元素对象后，再调用 `get_text()` 或 `click()` 可返回 Code 106（元素 ID 失效）。不要把它简单归因为 XPath 错误、广告遮挡或等待时间不够。

- 每次轮询重新查询当前任务列表；动态变化快时，可通过 `page.execute_javascript()` 在**当前 DOM** 中一次读取行文本，拿到普通数据后再判断。
- 准备点击下载时重新定位本次唯一任务，不能长期持有上轮的 WebElement。
- DOM 读取只能解决陈旧元素引用问题，不能替代“本轮唯一任务”的业务判断；XPath、选择器及点击方式应按当前真实页面验证。
- 遇到 Code 106 时先确认页面有无重绘、弹窗遮挡、登录跳转或 Profile 切换，再决定最小修复，不把 JavaScript 点击写成万能 fallback。
