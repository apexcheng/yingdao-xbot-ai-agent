## 参考边界

这些源码证明“该项目在这个 commit 中真实这样实现过”，不表示所有新项目都应该照搬。

不得直接泛化的内容包括：

- 平台页面 XPath、按钮文案、URL 和网络请求特征。
- 库存阈值、停止扫描数量、重试次数和通知时间等业务参数。
- 数据库字段是否适用于其它业务。
- 拼多多 / 天猫当前页面结构和登录方式。
- 来源项目中仍存在的 TODO、调试痕迹和局部历史代码。

具体 API 调用先以 `xbot-api-docs/` 为准，代码风格和开发行为先以 `project-template/AGENTS.md` 与 `docs/coding-style.md` 为准。
