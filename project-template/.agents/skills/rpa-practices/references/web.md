# 网页自动化实践

## 页面操作与数据获取分离

**优先级：网页网络响应 → DOM 数据提取。** 能从 XHR / Fetch 等响应中读取完整、可信的业务数据时，DOM / XPath 只负责搜索、点击查询、排序、翻页等交互，不再滚动虚拟列表或逐行读取网页元素。由网页自身触发请求，不等于必须由 RPA 单独构造 HTTP 请求。

1. 先确认目标业务数据是否随网页请求返回，核实响应结构、必要字段与时间单位；请求包通常携带查询条件，实际业务数据应优先从**响应包**读取。
2. **先启动网络监听，再执行 DOM 动作**，等待该动作对应的响应后解析数据；查询、翻页均依此重复。影刀原生 `start_monitor_network()` / `get_responses()` / `stop_monitor_network()` 用法见 [browser.md](../../../../../xbot-api-docs/docs/browser.md#23-网络监听和请求)。
3. 同一份业务数据不要再从 DOM 读取并交叉等待，避免虚拟滚动、元素刷新和重复解析；但 DOM 仍可用于确认按钮状态、触发下一页。
4. 只有请求响应加密、缺少必要字段、无法可靠取得等情况被核实后，才降级 DOM 提取，不默认同时维护两套提取方案。接口契约未核实时，不猜测字段名或将错误数据写入业务文件。
5. **用户给出用于读取业务数据的 XPath 时**，不要为此打开浏览器或探测网络响应，直接问用户：**「确认不通过网络响应，而是使用 XPath 提取数据吗？」** 用户确认后按 XPath 方案执行，未确认前暂停该数据提取方案；用于交互（查询、翻页、排序等）的 XPath 正常使用，无需询问。

以下是后台异步导出任务及动态页面的专项经验。

## 绑定本轮导出任务

同一时间窗口可能已有历史导出任务，默认通过**导出前任务列表快照 + 导出后新增任务比对**识别本轮目标：

1. 导出前读取当前任务列表作为快照，再执行导出动作；若平台直接返回可靠、可追踪的唯一任务 ID，可以使用该 ID，不必额外读取快照。
2. 导出后查询任务列表，与快照比对新增任务；可结合任务 ID、唯一任务名、文件名和任务分类识别本轮目标。无法直接确定时，再使用本轮触发时间辅助筛选。
3. **候选必须唯一**，才能等待它变为可下载状态并点击对应下载；多条同时匹配或无法区分历史任务时直接报错，不选第一条。
4. 取得本轮下载的文件路径后直接交给业务处理；不额外验证文件存在性、表头、第一行或业务结构。

压缩包解压与多文件目标识别参阅 [xzip.md](../../../../../xbot-api-docs/docs/xzip.md)；网页下载和等待 API 参阅 [browser.md](../../../../../xbot-api-docs/docs/browser.md)。

## Page 与下载操作

- 未登录时先完成登录，登录成功后**新建 Page 打开目标业务 URL，并关闭旧登录 Page**；不依赖登录 Page 自动跳回原网址。
- 非表格更新场景，需要重试的下载操作最多执行 3 次（首次加 2 次重试）；下载失败时重试完整下载过程，不为重试额外增加框架。表格更新按 [表格操作 Skill](../../spreadsheet-operations/SKILL.md) 执行整个 Sheet 最多 2 次尝试，不套用这里的下载重试次数。
- Page 新建、跳转、刷新后，先 `page.wait_load_completed()`，再 `time.sleep(2)`，再操作业务页面；启动清理 Page 和异常保留当前 Page 的规定见项目 `AGENTS.md`。

## 动态任务表：避免过期网页元素

React / SPA 后台任务中心可能在数据刷新时替换整行 DOM。实测 Shopee 中，保存 `row` 或 `td` 的影刀元素对象后，再调用 `get_text()` 或 `click()` 可返回 Code 106（元素 ID 失效）。不要把它简单归因为 XPath 错误、广告遮挡或等待时间不够。

- 每次轮询重新查询当前任务列表；动态变化快时，可通过 `page.execute_javascript()` 在**当前 DOM** 中一次读取行文本，拿到普通数据后再判断。
- 准备点击下载时重新定位本次唯一任务，不能长期持有上轮的 WebElement。
- DOM 读取只能解决陈旧元素引用问题，不能替代“本轮唯一任务”的业务判断；XPath、选择器及点击方式应按当前真实页面验证。
- 遇到 Code 106 时先确认页面有无重绘、弹窗遮挡、登录跳转或 Profile 切换，再决定最小修复，不把 JavaScript 点击写成万能 fallback。
