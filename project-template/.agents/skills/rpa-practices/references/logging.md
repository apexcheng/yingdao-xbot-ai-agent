# 中文业务上下文日志

## 适用范围与格式

影刀编码版的业务过程日志默认采用 **业务上下文 + 自然语言动作 + 必要事实**，方便直接判断程序做了什么、成功没有、失败在哪里。

```text
【业务对象】操作：动作｜必要信息
【平台】店铺：动作｜必要信息
```

- 上下文按业务选用平台、店铺、Sheet、任务或系统等；不强制两级前缀，名称已经带有 `【】` 时不再嵌套包装。
- 正文用中文描述动作与结果，必要的文件名、商品 ID、SKU、范围、数量、日期及失败原因用 `｜` 分隔；并非每项都必须写成 `键=值`。
- 影刀面板已有时间与日志级别，不在每条正文重复拼接时间、`level`、`seq`、`stage`、`event`、`status`、`detail` 等技术字段。
- `run_id` 等标识如确有跨工作簿、通知、文件的追溯需求，可保留于业务状态和归档文件名，不必逐行重复。

## 日志示例

```text
【系统】跨境补货表：开始执行
【浏览器】Chrome：清理历史页面完成｜关闭=4｜保留=1
【雅仓库存】下载：下载完成｜文件=库存导出.xlsx｜耗时=12.3秒
【雅仓库存】RAW更新：写入完成｜1199条｜15列
【跨镜】马来西亚：销量写入完成，等待保存｜更新1天｜SKU=285
【WPS】目标工作簿：保存成功
【系统】跨境补货表：执行完成｜成功=8｜失败=0

【拼多多】BOW旗舰店：扫描第1页｜消息数=20
【拼多多】BOW旗舰店：库存更新成功｜商品ID=123456｜SKU=789012｜库存=0→50
```

避免把技术字段堆叠成正文：

```text
不推荐：run_id=xxx｜seq=12｜level=INFO｜task=雅仓库存｜stage=写入｜event=完成｜status=pending_save｜detail=写入完成｜rows=1199
推荐：【雅仓库存】RAW更新：写入完成｜1199条
```

## 信息密度与失败

- 正常流程记录关键业务节点和实际结果；不机械地为每个点击、`get_range`、`set_range` 或进程清理命令生成“开始 / 完成”成对日志。
- 长时间等待、下载、跨地区处理等步骤，按排查需要记录起点、关键进度及最终结果；不逐次打印无变化的轮询。
- 重试按实际需要记录第几次失败、原因和是否继续；正常首次成功无需显示 `1/3`。最终失败由负责处理该异常的边界输出完整堆栈；同一异常不在多层反复记录。
- **日志记录不等于异常已通知。** 对已要求异常钉钉告警的任务，检查每个异常出口是否进入通知或本轮异常汇总：包括捕获后继续、重试失败、解析失败、降级使用旧数据、部分对象失败及运行收尾失败。不能因为主流程最终返回成功，或只写了 `error` / `warning` 日志，就把已发生的异常视为正常。
- 日志需保留异常发生的业务对象、步骤、原因、影响范围和实际处理结果（重试 / 降级 / 跳过 / 中断），避免只有孤立的 XPath 或接口报错；发送频率、是否 @ 人和正常业务跳过的口径由项目规则决定。
- 写入完成但尚未保存时，应明确说“等待保存”；保存失败、某项部分写入、跳过与未执行都应准确表达，不把处理完成冒充最终保存成功。
- 已配置凭证及敏感数据不进入日志；必要时脱敏。钉钉通知面向业务处理者，只呈现结果和待处理事项，不照搬运行日志或完整堆栈。
- 有执行结果通知的多对象任务，日志在真实操作点保留对象、阶段、成功/跳过/失败事实及可定位的错误原因；通知汇总这些已确认事实，不得用“没写入”代替“没执行”。日志与通知的详细状态表达统一参见[钉钉通知实践](dingtalk.md)，不另建一套状态表或通知规则。

```text
【雅仓库存】下载：第2次失败，准备重试｜原因=等待导出超时
【雅仓库存】下载：最终失败｜已尝试3次｜原因=导出任务一直未完成
异常堆栈：
Traceback (most recent call last):
    ...
```

## 实现边界与参考

- 简单项目可直接 `logging.info(f"【雅仓库存】RAW更新：写入完成｜{count}条")`；仅在平台、店铺、商品 ID 等上下文持续重复、统一输出确有价值时，才封装日志格式函数或 `ContextLogger` 一类对象。**不强制类名、接口或封装。**
- 日志对象只负责怎么记录，不决定重试、停止、保存或业务状态。日志与异常边界见 [编程风格](../../code-quality/references/coding-style.md)。
- API 签名与日志级别以 [影刀日志 API](../../../../../xbot-api-docs/docs/logging.md) 为准；真实实现可按需参考 [库存监控日志源码快照](../../../../../reference-projects/inventory-monitor/snapshot/utils.py)，快照仅代表来源项目当时的实现。
